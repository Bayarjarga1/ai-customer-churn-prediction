AI-Powered Customer Churn Prediction System

This project uses machine learning to identify customers who are likely to leave, helping businesses take proactive retention actions.

Business Goal

Predict churn before it happens.

AI Method

Random Forest + SMOTE + Threshold Tuning

Final Output

Churn probability and business recommendation.

Business Problem

Customer churn is a major challenge for subscription-based businesses. Losing customers reduces revenue, increases acquisition costs, and lowers long-term profitability.

AI Solution Design

Machine Learning

Supervised classification was used to predict churn.

Random Forest

Selected because it performed better for churn recall.

SMOTE

Used to handle class imbalance in the churn dataset.

Flask Website

Integrated the model into an interactive web demo.

Implementation Process

1. Dataset preprocessing
2. One-hot encoding
3. 80/20 train-test split
4. SMOTE balancing
5. Model training and evaluation
6. Flask deployment

Key Drivers of Customer Churn

Feature importance shows that customer satisfaction, tenure, engagement, revenue, and contract-related variables strongly influence churn behavior.
